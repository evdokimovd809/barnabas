# Личный кабинет менеджера (Barnabas)

Открыть в браузере:

**Локально:** http://localhost:3002/console/index.html

## Как попасть

1. Откройте ссылку выше.
2. Нажмите «Регистрация менеджера».
3. Введите **ключ менеджера** (он хранится в Firebase в коллекции `managerKeys`).
4. Создайте логин/пароль — попадёте в панель.

## Что видно в панели

- **Обзор** — KPI: новые заказы, в работе, доход платформы, средняя оценка, attention-лист.
- **Заказы** — все заказы с фильтрами: непроверенные, идут предложения, без предложений, в работе, ждут подтверждения, просроченные, выполненные, отменённые. Карточка заказа: адрес, цена, исполнитель, этапы, чат, история событий.
- **Люди** — исполнители, заказчики, менеджеры, онлайн, непроверенные, заблокированные. Профиль: анкета, верификация, блокировка, статистика.
- **Лента** — live-события (создание заказа, предложения, выбор, этапы, отзывы, действия менеджеров).
- **Чаты** — support-диалоги и чаты по заказам.
- **Настройки** — комиссия, режим удержания, лимиты.

## Технические детали

- Панель — автономный `console/index.html` (Firebase Auth + Firestore, те же SDK, что и основное приложение).
- Проект Firebase: `barnabas-5f744`.
- Правила доступа: `firestore.rules` (только менеджеры с валидным ключом читают все коллекции).
- Для локального теста с эмуляторами: добавьте `?emu=1` (эмуляторы поднимаются через `npm run emulators`).
