# Барнабас v3 — «inDrive для мастеров»

Сайт: https://evdokimovd809.github.io/barnabas/ · Firebase: barnabas-5f744 · правила: firestore.rules (публикуются вручную в консоли).

## Суть
Заказчик описывает задачу, ставит точку на карте и называет свою цену. Мастера рядом видят заказ и либо соглашаются на цену заказчика одним нажатием, либо предлагают свою. Заказчик в реальном времени видит предложения: цену, анкету, рейтинг, расстояние. Принимает одно, остальные отклоняет. Дальше — чат по заказу, этапы работы («выехал → начал → закончил»), подтверждение и отзыв. Оператор видит каждое действие.

## Заказчик
- Заказ: услуга, задача, подробности, фото, адрес (улица/дом — видят мастера; квартира/подъезд — только выбранный мастер), точка на карте, когда, своя цена.
- «Поднять цену» (+500 / +1000 / +2000), пока ждёт предложений.
- Предложения: Принять / Отклонить прямо в списке, анкета по нажатию.
- После выбора: чат с мастером внутри платформы (оператор его видит), этапы работы, «Работа выполнена», отзыв.

## Исполнитель
- Лента «Заказы рядом»: сортировка по расстоянию, радиус, категории, поиск, вид списком или на карте.
- «Взять за цену заказчика» одним нажатием или «Предложить свою цену» (быстрые +10/20/30%).
- Видит, отклонили ли его предложение; может предложить другую цену.
- Выбранный заказ: полный адрес, маршрут в 2ГИС/Яндекс, чат, кнопки этапов.

## Оператор (менеджер)
- Обзор: что требует внимания (поддержка ждёт, заказы без предложений, просроченные, непроверенные мастера), доход, кто онлайн.
- Лента: все действия всех людей в реальном времени, фильтры и поиск.
- Заказы: всё по заказу + хронология событий, предложения, чат сторон, назначить мастера вручную (подбор по специальности, расстоянию, рейтингу), сменить статус.
- Люди: поиск, телефон, Telegram, когда был онлайн, хронология действий, «проверен», блокировка.
- Чаты: поддержка и чаты заказов.

## Масштаб (50+ человек и больше)
- Каждый загружает только своё: заказчик — свои заказы, мастер — открытые и свои, оператор — всё.
- Телефоны вынесены в закрытую коллекцию `private` (видят владелец и оператор).
- Отзывы — в коллекции `reviews` (рейтинг считается без загрузки чужих заказов).
- Действия — в коллекции `events` (читает только оператор).
- Составные индексы Firestore не нужны.

## Как выпустить v3
1. Опубликовать `firestore.rules` в Firebase → Firestore → Правила (или `npm run deploy:rules`). Сначала правила, потом сайт.
2. Отправить код на GitHub (`send-to-github.bat`).
3. Оператору один раз открыть консоль: старые данные перенесутся сами (телефоны → `private`, отзывы → `reviews`, имена заказчиков в заказах).
4. Старые заказы без точки на карте видны мастерам, но без расстояния. Новые заказы без точки опубликовать нельзя.
